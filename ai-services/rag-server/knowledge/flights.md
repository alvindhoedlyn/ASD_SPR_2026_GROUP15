## Recommendation boundaries

The Flight Recommender does not claim to provide booking, payment, seat inventory, baggage
inclusions, airport transfers, or live airline prices. If the approved context does not contain the
requested fact, the RAG service must return an insufficient-context response instead of inventing it.
